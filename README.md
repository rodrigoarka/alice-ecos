# ♠♥ Alice - Ecos no País das Maravilhas ♦♣

### _Um Sistema Oficial para Foundry VTT (Engine E.C.C.O.S.)_

Bem-vindo à toca do coelho. **Alice - Ecos no País das Maravilhas** é um sistema de RPG de mesa focado em Sobrevivência e Nonsense, rodando sob a **Engine E.C.C.O.S.** Este módulo adapta todas as regras do jogo para o **Foundry Virtual Tabletop**, oferecendo uma interface customizada que mistura o requinte Neo-Vitoriano com a agressividade visual de um Zine Punk (Gótico Tropical) regado a luzes neon.

A realidade quebrou. A lógica foi enforcada. Role os dados.

---

## 👁️ Funcionalidades do Sistema

- **Design Zine Punk:** Fichas de personagem e de itens totalmente estilizadas com CSS Grid/Flexbox, simulando recortes, polaroids com fita adesiva, papéis de máquina de escrever e muito neon (Amarelo, Ciano e Rosa Choque).
- **Rolagem do Absurdo Automatizada:** Clique nos atributos (Forma, Lógica, Devaneio) direto da ficha para abrir o pop-up do Coelho Branco. O sistema calcula a dificuldade, bônus de Vivência, penalidades e joga os D6 no chat automaticamente.
- **Leitura de Dados E.C.C.O.S.:** O chat julga instantaneamente os sucessos (5,6), custos (4) e falhas (1). Comemora o "Decreto da Rainha" (Crítico) e pune com os "Olhos de Cheshire" (Falha Crítica Fatais).
- **Inventário Dinâmico:** Arraste e solte. O sistema lê o vínculo dos "Conceitos" criados e os joga automaticamente para as abas corretas (Forma, Lógica, Devaneio, Defeitos ou Itens de Bolso).

## 🐇 Como Instalar no Foundry VTT (Versão 13+)

Para trazer o País das Maravilhas para a sua mesa, siga os passos:

1. Abra o seu Foundry VTT e vá até a aba **Sistemas de Jogo (Game Systems)**.
2. Clique no botão **Instalar Sistema (Install System)**.
3. No campo inferior _URL do Manifesto_, cole o link abaixo:
   `https://raw.githubusercontent.com/rodrigoarka/alice-ecos/main/system.json`
4. Clique em **Instalar**.
5. Crie um novo Mundo e selecione "Alice - Ecos no País das Maravilhas" como sistema!
